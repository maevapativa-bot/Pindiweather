Crée une application complète appelée "LeisureFlow" — une app de gestion du temps libre.

★ MODÈLES SEQUELIZE (backend/src/models/) :

1. User.js :
   - id (UUID, primaryKey), email (unique, not null), password (not null, hashed), username, firstName, lastName
   - preferences : { theme, language, notifications, weatherUnit }
   - timestamps, hooks : beforeCreate/beforeUpdate → bcrypt hash password
   - instance method : validatePassword(plain) → bcrypt.compare

2. Activity.js :
   - id (UUID), userId (FK → User), title, description, category (enum : outdoor, indoor, sport, culture, food, social, other)
   - duration (minutes), difficulty (easy/medium/hard), isPublic (default false)
   - weatherConstraints : { minTemp, maxTemp, maxWindSpeed, maxRainProb, requiresSunshine }
   - location : { lat, lon, name, radius }
   - tags (ARRAY STRING), images (ARRAY STRING)
   - completionCount, rating, timestamps

3. Event.js :
   - id (UUID), userId (FK), activityId (FK → Activity), title
   - scheduledAt, duration, status (enum : planned/confirmed/completed/cancelled/postponed)
   - actualWeather (JSONB), weatherScore (0-100)
   - notes, isRecurring, recurrenceRule, timestamps

4. WeatherCache.js :
   - id, lat (DECIMAL 9,6), lon (DECIMAL 9,6), data (JSONB), fetchedAt, expiresAt
   - Index composite sur (lat, lon), scope : isExpired()

5. UserSession.js :
   - id (UUID), userId (FK), token (unique), deviceInfo (JSONB), expiresAt, isActive

★ MIDDLEWARE (backend/src/middleware/) :

1. auth.js — middleware JWT :
   - Extrait Bearer token du header Authorization
   - Vérifie avec jwt.verify + JWT_SECRET
   - Charge l'utilisateur depuis DB (sans password), attache à req.user
   - Gestion erreurs : TokenExpiredError, JsonWebTokenError → 401

2. errorHandler.js — gestionnaire d'erreurs global :
   - Capture toutes les erreurs Express
   - Format de réponse standard : { success: false, error: { code, message, details? } }
   - Log avec Winston (level error pour 500, warn pour 4xx)
   - Masque les détails en production

3. rateLimiter.js — express-rate-limit :
   - globalLimiter : 100 req/15min
   - authLimiter : 5 req/15min (pour login/register)
   - weatherLimiter : 30 req/min

4. validator.js — wrappers express-validator :
   - validateRequest(rules) : middleware qui applique les règles et renvoie 400 si invalide
   - Règles authRules : email valide, password min 8 chars, username alphanumérique

★ AUTH CONTROLLER + ROUTES (backend/src/controllers/authController.js + routes/auth.js) :

Routes :
- POST /api/auth/register
- POST /api/auth/login
- POST /api/auth/logout
- GET  /api/auth/me (protégé)
- POST /api/auth/refresh

Logique :
- register : validation, unicité email/username, hash password, créer User + UserSession, retourner JWT
- login : trouver user, valider password, créer session, JWT avec payload {userId, email, sessionId}
- logout : invalider session (isActive = false)
- me : retourner user sans password
- Tokens JWT : accessToken (1h) + refreshToken (7j) stockés dans UserSession

★ WEATHER SERVICE (backend/src/services/weatherService.js) :

Appel OpenWeather One Call API 3.0 :
- URL : ${OPENWEATHER_BASE_URL}?lat={lat}&lon={lon}&appid=${OPENWEATHER_API_KEY}&units=${WEATHER_UNITS}&lang=${WEATHER_LANG}&exclude=minutely
- fetchWeatherFromAPI(lat, lon) : appel axios, timeout 10s, retry 2x sur erreur réseau

Cache Redis :
- Clé cache : `weather:${lat.toFixed(4)}:${lon.toFixed(4)}`
- TTL : WEATHER_CACHE_TTL secondes (300 par défaut)
- getWeatherWithCache(lat, lon) : vérifie Redis → si miss, appel API → store Redis → retour
- invalidateWeatherCache(lat, lon) : deleteCache

Transformation des données :
- transformCurrentWeather(data) : {temp, feelsLike, humidity, pressure, dewPoint, uvIndex, visibility, clouds, wind:{speed, speedKmh, deg, gust, direction}, weather:[{id,main,description,icon,iconUrl}], isDay, isOutdoorFriendly, comfortLevel:{score,label}}
- transformHourly(data) : tableau 48h avec {dt, temp, feelsLike, humidity, wind, weather, pop, rain, snow}
- transformDaily(data) : tableau 7j avec {dt, dayName, temp:{min,max,day,night}, feelsLike, humidity, uvIndex, wind, weather, pop, rain, snow, isOutdoorFriendly}
- isOutdoorFriendly(weather) : true si temp 5-35°C, vent <50km/h, pluie <70%, pas d'alerte

Calcul comfortLevel :
- score 0-100 basé sur temp (25°C = 100), humidité (50% = 100), vent, UV
- labels : Idéal / Agréable / Correct / Inconfortable / Dangereux

★ HOOK useWeather (mobile/src/hooks/useWeather.ts) — avec React Query v5 :
- Utilise useLocation() pour récupérer les coordonnées GPS
- Arrondit les coordonnées à 4 décimales dans le queryKey (évite refetch si GPS flotte de quelques mètres)
- Envoie les coordonnées à 6 décimales à l'API (précision maximale)
- queryKey: ['weather', roundCoord(lat, 4), roundCoord(lon, 4)]
- queryFn: appelle getCurrentPositionAsync(Highest) pour coord fraîche PUIS fetchWeather
- enabled: !!location
- staleTime: 2 * 60 * 1000
- gcTime: 30 * 60 * 1000  (React Query v5 — pas cacheTime)
- refetchInterval: 5 * 60 * 1000
- retry: 1
- Cache AsyncStorage : loadCache() lit "@leisureflow_weather_cache", utilise si < 30 min. saveCache(data) écrit avec _cachedAt timestamp.
- Fallback sur cache si erreur réseau

★ UTILITAIRE (mobile/src/utils/geo.ts) :
export function roundCoord(value: number, decimals = 3): number {
  const factor = Math.pow(10, decimals);
  return Math.round(value * factor) / factor;
}
